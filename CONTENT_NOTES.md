# Current paper and project-page provenance

The project page is aligned to the active Overleaf checkout recorded in `content/manuscript-revision.txt`. The source copies and exact rendered passages are in `content/manuscript-sources/` and `content/manuscript-excerpts.json`. The extractor refuses stale passages; the page audit checks all rendered research prose against those passages.

The final paper is titled *OmniTaskonomy: When Does Visual Generation Improve Visual Understanding*. The taxonomy and transfer experiment contain 19 I2I supervision tasks and 25 I2T capability leaves. The interactive tree and heatmap use the same 19-source inventory. The main heatmap displays the 19 capabilities with more than 100 evaluation examples; the full data has 25 capabilities and 9,444 examples. The site does not change the manuscript or bibliography.

The teaser PNG is rendered from `iclr2026/figures/Figure1-analysis_teaser_v19.pdf`. The controlled example and scaling PNGs are cropped from `iclr2026/figures/combined_3subfigures_refined_v18.pdf`. The interactive gradient bars use the exact module and layer values in `analysis/section6/data/initial_graph_data.json`. The two transfer scatter panels are cropped from the final `gradient_transfer_overview_v5.pdf`, because the checkout does not contain the complete 19-source raw alignment table needed to reproduce its 133 interactive points.

Every displayed leaf node has a representative image. Colorization uses the exact example images in the paper's `analysis/unitaskonomy_examples/manifest.json`. Inpainting, localization, semantic segmentation, object editing, attribute editing, and Jigsaw use the paper's current examples. The 19-column heatmap comes from the same paired-results export used by the final paper. The I2I tree order is recorded separately from the figure column order.

The transfer map does not display significance stars. Its on-page excerpt stops before the manuscript's significance sentence; no significance inference is made from the visual alone. The site keeps the requested pending BibTeX placeholder. Its Paper button serves the compiled final manuscript, its GitHub button links to the public repository, and no Hugging Face button is shown without an authoritative destination. The final author list, affiliations, contribution notes, and correspondence are pinned in `content/paper-metadata.json`. The website design acknowledgment to Beyond Language Modeling appears only in the footer. The site metadata is indexable because the final manuscript is public and names the project page.

The final manuscript now describes Zoom-In without the earlier five-view wording and uses the current instance-level table. The project page follows these final passages verbatim.

The BAGEL attention architecture diagram is an original, code-derived illustration. It is pinned to the official ByteDance-Seed/Bagel `a2fa77dd8caeefc41e6607ae0ec17408d3f4ee9f` implementation in `modeling/bagel/qwen2_navit.py` (`PackedAttentionMoT` and `Qwen2MoTDecoderLayer`) and `modeling/bagel/bagel.py` (modality token packing). The current manuscript describes modality-specialized Transformer parameters with shared attention, which matches the implementation only when “shared attention” means the attention operation over packed modality-specific Q/K/V states, subject to the model's mask. Q/K/V and output projections, normalization, and MLP are not shared parameters across the two branches. The on-page caption is exact manuscript text from `sections/3_poc.tex`.

The TL;DR Jigsaw teaser is an HTML animation built from the author-supplied `jigsaw_input.png` and `jigsaw_output.png`. Its four patches are cropped from the input by `scripts/build-tldr-teaser.py`, which checks that the supplied output equals the input rearranged by the figure's answer `('reorder', [3, 2, 1, 0])`. The panel titles, answer, and patch indices are the figure's own labels, recorded in `content/tldr-teaser.json`. The page renders the completed state for readers without motion.
